# Deep Research & Comparative Matrix: Azeroth 5v5 Mid-Only MOBA

## 1. Open-Source Repository & Engine Discovery: *Azeroth Survivors*

> [!IMPORTANT]
> **Key Architectural Finding:** *Azeroth Survivors* is **not** a traditional C++ TrinityCore/AzerothCore server script. Both the original game by Aethus (`wow.aethus.pl` / `AzerothSurvivors.exe`) and its open-source recreation run on a **from-scratch Rust + Bevy World of Warcraft 1.12.1 engine** that reads standard `Data/*.MPQ` archives and compiles to both **native desktop binaries** and **WebAssembly/WebGPU** for zero-install browser play.

## 2. Two Viable Technical Foundations for Your 5v5 Custom Game

| Dimension | Path A: `azeroth-survivors-re` (`benilla` / `wenilla` Rust + Bevy Engine) | Path B: Traditional WoW 3.3.5a Server (`TSWoW` / `AzerothCore` + Custom Client Patch) |
| :--- | :--- | :--- |
| **Core Technology** | 100% Rust + Bevy ECS reading WoW 1.12.1 MPQs. Runs natively OR in a web browser via WebAssembly/WebGPU. | C++ Server (`TrinityCore`/`AzerothCore`) + TypeScript modding (`TSWoW`) + legacy `Wow.exe` (3.3.5a) client. |
| **Player Onboarding** | **Zero-install browser URL** (like `wow.aethus.pl`) OR lightweight standalone executable; supports WebRTC/WebSocket multiplayer. | Players must download a multi-GB 3.3.5a client + custom `.MPQ` patches + configure `realmlist.wtf`. |
| **Camera & Controls** | Native top-down MOBA/ARPG camera (61° fixed or free 3D orbit), WASD or click-to-move, cursor skillshots out of the box. | Locked to standard 3rd-person MMO tab-targeting camera unless heavily reverse-engineered via DLL injection. |
| **Custom UI (Cards, Shop, Draft)** | Native Bevy UI + optional Lua 5.1 FrameXML. Trivial to build 3D tilting upgrade cards, MOBA shop grids, and lane minimaps. | Requires complex backported Lua/FrameXML addons (`AIO` / `TSWoW` client-server messaging) inside 2008 Lua 5.1 constraints. |
| **Networking Model** | Can use `benilla-protocol` (1.12 world packets), custom Bevy authoritative server over WebSockets/WebRTC, or P2P Host-Star. | Built-in authoritative MMO networking for 10+ players, battleground queues, and combat validation, but rigid MMO tick rates. |
